## This folder

- `assets/*.jpg` — editorial illustrations (replace before commercial print)

- Crop marks: included

- Safe margin: 12 mm inside trim
- Fonts embedded: Fraunces, IBM Plex Sans, IBM Plex Mono
- ISSN and legal deposit: pending
